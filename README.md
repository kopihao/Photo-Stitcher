# Photo Stitcher - Private & Offline

A Progressive Web App (PWA) to stitch photos together vertically.

## Overview
Photo Stitcher is a client-side image processing application that enables users to combine multiple photos vertically without compromising data privacy. Built with modern web technologies, it operates entirely within the browser environment, ensuring zero data transmission to external servers.

## Key Features
- **Privacy-First** - All image processing happens in your browser
- **Works Offline** - Full functionality without internet connectivity after initial load
- **Multi-language** - Support for 20+ languages
- **Installable On Mobile** - Add to home screen on Android/iOS
- **Zero Latency** - No server uploads, no network delays, instant processing

## Privacy & Security
**Data Sovereignty Guarantee:**
- ✅ 100% client-side processing
- ✅ Zero server uploads
- ✅ No data collection or analytics
- ✅ No third-party integrations
- ✅ Your photos never leave your device

Ideal for organizations and individuals requiring strict data privacy compliance.

## Use Cases
- Document compilation
- Screenshot consolidation
- Social media content creation
- Receipt and invoice management
- Privacy-sensitive image processing
